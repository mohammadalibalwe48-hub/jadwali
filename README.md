# جدولي (Jadwali)

منظّم جدول جامعي خفيف ومخصّص للموبايل، يدعم **المسح المحلي بدون مفاتيح API** ومسحاً اختيارياً بنموذج رؤية، وجاهز للنشر المباشر على **Vercel**.

## الميزات
- **قراءة ضوئية (OCR) مباشرة بالمتصفح:** يستخرج المواد والأوقات والقاعات ونوع المحاضرة (نظري/عملي) تلقائياً عبر `Tesseract.js` بدون الحاجة لأي اشتراك أو مفتاح.
- **صور الجداول المطبوعة ولقطات الشاشة:** يتتبّع قارئ الصور حدود الخلايا لربط كل محاضرة بيومها ومادتها، حتى عندما تحتوي الخلية على أكثر من موعد. يدعم الجداول العربية والإنكليزية. احرص على ظهور أسماء الأيام وحدود الجدول في الصورة وراجع النتائج قبل التصدير.
- **تحديد الطوابق تلقائياً:** يطبّق نظام رموز القاعات (`B = القبو`، `المدرّج = الأرضي`، `F = الأول`، `S = الثاني`، `L = الخامس`) مع إمكانية تخصيص القواعد.
- **تصدير PDF متجهي بصفحة واحدة:** عبر Vercel Serverless Function (`api/pdf.ts`) متوافق مع iPhone وAndroid والكمبيوتر.

## استيراد الجداول

- يدعم قارئ الصور الجداول الأسبوعية التي يمتد فيها اسم اليوم عبر عدة محاضرات. تظهر نتائج المسح للمراجعة قبل إضافتها.
- لاستيراد جدول بوابة مقسّم أفقياً، اختر لقطة تُظهر أسماء المقررات ورموزها ولقطات تُظهر أعمدة الأيام والأوقات من الجدول نفسه. اترك كل الصفوف ظاهرة بالترتيب نفسه، بما فيها الصفوف الفارغة. يمكنك استكمال الدفعة بزر «أضف لقطات لهذا الجدول».
- يبقى المسح العادي في المتصفح. عند اختيار «مسح بنموذج رؤية»، تُرسل الصور إلى الخدمة المختارة عند بدء المسح.

### نموذج مجاني على جهازك

ثبّت [Ollama](https://ollama.com/download) وشغّله. يستخدم المثال نموذج [Qwen3-VL 8B Instruct](https://huggingface.co/Qwen/Qwen3-VL-8B-Instruct) بترخيص Apache 2.0.

```sh
ollama pull qwen3-vl:8b
JADWALI_OLLAMA_URL=http://127.0.0.1:11434 npm run dev -- --host 127.0.0.1
```

ارفع الصور واختر «مسح بنموذج رؤية» ثم «Ollama». يتطلب النموذج ذاكرة ووقت معالجة على الجهاز. يمكن تحديد نموذج Ollama آخر باستخدام `JADWALI_OLLAMA_MODEL`.

على Vercel، يتطلب خيار Ollama خادماً يمكن الوصول إليه عبر HTTPS. اضبط `JADWALI_OLLAMA_URL` و`JADWALI_OLLAMA_ACCESS_CODE` في بيئة الخادم. إذا كان خادم Ollama يتطلب مصادقة Bearer، اضبط `JADWALI_OLLAMA_TOKEN` أيضاً. يمكن استخدام خيار Vercel AI Gateway بمفتاح شخصي من شاشة المراجعة، وقد تُحتسب رسوم على المفتاح.

### اختبار الاستيراد

- `npm run test:import` يختبر عينات صور مُعاد إنشاؤها في Chromium. شغّل `npm run dev` أولاً. يمكنك ضبط `CHROMIUM_PATH` و`JADWALI_TEST_URL` عند الحاجة.
- `npm run test:vision` يختبر اتصال Jadwali بواجهة Ollama باستخدام خادم اختباري.

## النشر على Vercel
1. ارفع المشروع على مستودع GitHub.
2. اربط المستودع مباشرة على Vercel واضغط **Deploy** بدون الحاجة لأي إعدادات إضافية.
